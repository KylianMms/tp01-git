git init :  est la toute première commande que l'on utilise pour démarrer un projet avec Git.

git status : sert à afficher l'état actuel de l'espace de travail ,indiquant en temps réel quels fichiers ont été modifiés, ajoutés ou ignorés depuis le dernier enregistrement.

git add : sert à ajouter les modifications des fichiers dans la zone de préparation  pour indiquer à Git quels changements inclure dans le prochain enregistrement (commit).

git commit : sert à enregistrer définitivement les modifications permanent dans l'historique de votre projet.
